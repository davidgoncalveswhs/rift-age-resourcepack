# Rift Age Resource Pack

Original pixel-art textures for a private Minecraft server's custom Umbra and Drift gear: six armor sets (Umbral, Nightfall, Voidheart, Prismite, Stormguard, Celestial), weapons, tools and materials.

- **Java Edition** (26.x, pack format 97): download `rift-age-java.zip` from the [releases](../../releases). The server sends it automatically on join.
- **Bedrock Edition** (via Geyser): `rift-age-bedrock.mcpack` plus Geyser custom item mappings, sent automatically by the server.

All art is generated by `make_pack.py` from the pixel grids in `art.py` (run `python3 make_pack.py`, needs Pillow).

## v2: mob and NPC skins
`mobs.py` repaints the vanilla textures of mob types that only the server's custom creatures use (Vex, Phantom, Zoglin, Vindicator, Strider, Endermite, Piglin Brute, Silverfish, Breeze, Happy Ghast, Hoglin, Allay, Evoker, Sniffer, Ravager, Parrot) plus the swamp and jungle villager types (Umbra and Drift robes). It keeps each mob's shading and layout and replaces the colors with themed gradients and glowing accents. Building needs local copies of the vanilla textures (`VANILLA_JAVA`, `VANILLA_BEDROCK` environment variables); none are stored in this repository. Mob outfits (Marsh Wight, Tidecaller, weekly boss themes) are original armor layers.
